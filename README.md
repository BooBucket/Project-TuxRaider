# Installation
1. Clone the repo (obviously)
2. Make changes in *main.cpp* file if you want (edit the map, add new features etc.)
3. Install SFML library (https://www.sfml-dev.org/)
4. Compile the script (on Linux: g++ main.cpp -o game -lsfml-graphics -lsfml-window -lsfml-system -lsfml-audio)
